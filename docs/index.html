Crusade

A self-hosted, no-API-key service search engine in the spirit of Shodan — scan reachable services, fingerprint them, enrich with geo/ASN/DNS/TLS, tag known vulns & public exploits, classify authentication posture, and search it all. For authorized security research.

RustSQLite + FTS5connect-and-read onlyno API keys
This page is a static overview. Crusade is a live server + scanner — it runs as a CLI / web app on your own machine or a VPS (or the published container image), not on GitHub Pages. Pages can only host static files; it cannot run the scanner, the database, or the web UI.

What it does

Discover & fingerprint

TCP/UDP scanning with a mandatory blocklist, nmap-service-probes fingerprinting, TLS certs, JARM, favicon mmh3, SSH intel, and ICS/OT device identification.

Enrich

GeoIP/ASN, reverse DNS, certificate-transparency subdomains, and optional web-UI screenshots.

Vulns & exploits

CVE matching (NVD + CISA KEV) cross-referenced to public exploits (Exploit-DB / Metasploit), plus heuristic tags.

Auth posture

Flags services reachable without credentials — open databases, ICS, VNC, admin panels — observed, never brute-forced.

Search

A Shodan-style query language over a local SQLite+FTS5 index, with facets, history, trends, a web UI and a JSON API.

Operate

Continuous rescans with webhook/email alerts, JSON-Lines export, and a distributed scan-worker queue.

Run it

# Container (published on each release)
docker run -p 127.0.0.1:8088:8088 ghcr.io/ilumci/crusade serve --bind 0.0.0.0:8088

# From source
cargo build --release
./target/release/crusade update-data
./target/release/crusade scan 203.0.113.0/24
./target/release/crusade search 'product:nginx country:DE has_exploit:true'
./target/release/crusade serve        # web UI at http://127.0.0.1:8088

Query language

port:net:country:asn:product:version:ssl.cn:jarm:http.favicon.hash:ssh.hostkey:hassh:ics:auth:vuln:has_exploit:tag: 
auth:open ics:modbus                  # unauthenticated industrial devices
has_exploit:true country:DE           # exploitable CVEs in Germany
product:nginx -has_vuln:true          # nginx without a known CVE
http.favicon.hash:-247388890          # same deployment, anywhere

Responsible use

Scan only what you own or are explicitly authorized to. Crusade connects and reads — it never exploits, brute-forces, or submits credentials — and a mandatory, un-bypassable blocklist skips private/reserved ranges. Internet-wide sweeps require a sanctioned scanning host and are your responsibility.
